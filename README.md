ブラウザで動くので PC・スマホの両方で遊べる。

## 動かす

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開く。

`npm run dev` はサーバー（ポート 2567）と画面（ポート 5173）を同時に起動する。
うまくいかないときは別々に起動してもいい。

```bash
npm run dev:server
```

```bash
npm run dev:client
```

### スマホの実機で開く

同じ Wi-Fi に繋いだスマホで、`npm run dev` が表示する `Network:` の URL を開く。

```
➜  Network: http://192.168.1.35:5173/
```

IP アドレスは環境で変わるので、毎回この表示を見ること。
サーバーの場所はクライアントが開いている URL のホスト名から組み立てるので、
設定を書き換える必要はない。

Windows のファイアウォールで Node.js の通信を許可するか聞かれたら、許可する。

### 公開モードで動かす

```bash
npm run preview
```

ビルドしてから、**サーバー1つで画面も WebSocket も配る**形で起動する。
公開したときと同じ形。手順は [05_公開手順.md](05_公開手順.md)。

### 確認する

```bash
npm run check
```

サーバー側のゲームロジック（戦闘・アイテム・階層移動・クリア・ゲームオーバー、
そして対戦のダメージに乱数が入っていないこと）をまとめて確認する。
ゲームを触る前に、まずこれを通すのが早い。

```bash
npm run typecheck
```

### 絵を描き直す

```bash
npm run sprites
```

`tools/make-sprites.mjs` の中の文字絵を書き換えて実行すると、
`public/sprites/tiles.png` が作り直される。1文字 = 1ピクセル。

本物の素材に差し替えるときは、同じ並び順（`src/shared/sprites.ts` の `SPRITE_INDEX`）で
16×16 のタイルを並べた PNG を同じ場所に置くだけでいい。
ライセンスは [CREDITS.md](CREDITS.md) に記録すること。

## 遊び方

| 操作 | スマホ | PC |
| --- | --- | --- |
| 移動 | 隣のマスをタップ | 矢印キー |
| 攻撃 | 敵のいるマスをタップ（体当たり） | 敵の方向へ矢印キー |
| 拾う | 「拾う」ボタン | `g` |
| 待機 | 「待機」ボタン | `.` |
| アイテム使用 | 「持ち物」→ 使うものをタップ | 同左 |

5F まで降りればクリア。HP が 0 になったらリロードでやり直し。

## 友達と遊ぶ

1. ページを開くとロビーが出て、部屋が1つ作られる
2. 「URL をコピー」で出てくる `?room=...` 付きの URL を友達に送る
3. 友達がその URL を開くと合流する（最大4人）
4. 「はじめる」で探索開始。後から合流もできる

全員の行動が揃うとターンが進む。1人が止まっていても **20秒で自動的に進む**ので、
放置した人がいても止まらない。回線が切れても **30秒以内に戻れば同じキャラで復帰**する
（スマホでアプリを切り替えたときのため）。

## いま動くもの

- サーバー権威でのターン進行（クライアントはルールを一切持たない）
- ダンジョン自動生成（矩形の部屋 + L 字の通路、21×21、5フロア）
- 視界と暗闇（部屋に入ると部屋全体／通路は足元だけ／通った場所は地形だけ記憶）
- 自キャラ中心 9×13 のカメラ
- モンスター3種と AI（見えたら近づいて殴ってくる）
- 体当たり攻撃、ゲームオーバー、5F 踏破でクリア
- アイテム5種（薬草・爆弾・剣・盾・転移の巻物）、拾う／持ち物／使う
- **マルチプレイ**（最大4人・URL で合流・同期ターン・20秒タイマー・切断と再接続）

## 構成

```
src/
├─ shared/   型とマスターデータ（サーバーとクライアントが両方 import する）
├─ server/   ゲームのルールは全部ここ
└─ client/   描画と入力だけ。計算はしない
check.ts     動作確認スクリプト
```

### 守っているルール

- **クライアントにゲームのルールを書かない。** 迷ったらサーバーに置く
- **乱数はサーバーだけが振る**（`src/server/random.ts`）。クライアントで `Math.random()` を呼ばない
- プレイヤーとモンスターは同じ `Actor` 型で扱う
- ダメージ計算は `calcDamage(..., { pvp })` を通す。v1.5 で対戦から乱数を消すための口

### 困ったときの見方

開発中はブラウザのコンソールで今の盤面が見える。

```js
__game.state            // 盤面まるごと
__game.state.actors     // 自キャラとモンスター
__game.send({ type: 'wait' })   // 手で行動を送る
```

本番ビルドでは消える（`import.meta.env.DEV` で囲ってある）。

### 使っているライブラリの注意

マルチプレイのクライアントは **`@colyseus/sdk`** を使う（`colyseus.js` ではない）。
`colyseus.js` は 0.16 系で止まっており、サーバー 0.18 のマッチメイキング応答を
読めずに接続が失敗する。
